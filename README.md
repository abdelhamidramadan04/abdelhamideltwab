# Assiut Sheets — Competitive Programming

A collection of my **C++ solutions for the Assiut Competitive Programming Sheets**.

This repository is created to practice competitive programming, improve problem-solving skills, and build a strong foundation in C++ and algorithms through solving problems step by step.

---

## 📚 About Assiut Sheets

The Assiut Sheets are a collection of programming problems designed to gradually build fundamental programming and problem-solving skills.

The repository follows the original sheet structure, with each sheet organized in a separate folder and each problem represented by an individual C++ source file.

The repository currently contains the following sheets:

1. **Data Types & Conditions**
2. **Loops**
3. **Arrays**
4. **Strings**
5. **Functions**
6. **Math & Geometry**
7. **Recursion**
8. **General Easy**
9. **General Medium**
10. **General Hard**

## 🗂️ Repository Structure

```text
assiut-sheets/
│
├── 01-data-types-and-conditions/
```

Each folder represents one sheet, and each problem is stored as a separate `.cpp` file.

For example:

```text

├── b-basic-data-types.cpp

└── ...
```
